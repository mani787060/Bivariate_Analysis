## Bivariate Analysis ##

# Overview:-
-> This project explores how two variables interact and influence each other using visualizations and statistical techniques.

# Concepts Covered:-
-> Correlation between numerical variables  
-> Relationship between categorical and numerical variables  
-> Scatter plots, heatmaps, and pair plots  
-> Covariance and correlation coefficients  

# Tools Used:-
-> Python (Pandas, NumPy, Matplotlib, Seaborn)
-> Jupyter Notebook

# Files:-
-> `bivariate_analysis.ipynb` → Main analysis notebook  
-> `dataset.csv` → Data used for analysis  

# Learnings:-
-> Gained deeper understanding of how variables relate to each other — an essential step before moving into multivariate analysis or predictive modeling.
